오류 처리 및 종료 코드(원인 + 힌트, exit != 0)

======================================================================
# 잘못된 날짜 형식(대화형, 재입력 안내 후 EOF 중단)
======================================================================

$ python -m budget_app add
  (입력: 2024-13-40\n)
날짜(YYYY-MM-DD): [오류] 날짜 형식이 올바르지 않습니다 (YYYY-MM-DD).
[힌트] 예: 2024-01-15
날짜(YYYY-MM-DD): [오류] 입력이 중단되었습니다.
[힌트] 필수 항목을 모두 입력하세요.
[exit code] 1

======================================================================
# 존재하지 않는 id 삭제
======================================================================

$ python -m budget_app delete --id TX-999999
[오류] 거래를 찾을 수 없습니다: TX-999999
[힌트] list 명령으로 존재하는 id 를 확인하세요.
[exit code] 1

======================================================================
# export 조건 누락
======================================================================

$ python -m budget_app export --out evidence/x.csv
[오류] export 는 --month 또는 --from/--to 조건이 필요합니다.
[힌트] 예: export --out out.csv --month 2024-01
[exit code] 1

======================================================================
# 사용 중 카테고리 삭제 차단
======================================================================

$ python -m budget_app category remove --name transport
[오류] 'transport' 카테고리를 사용하는 거래가 1건 있습니다.
[힌트] --into <대체카테고리> 로 거래를 옮긴 뒤 삭제하세요.
[exit code] 1

======================================================================
# 허용되지 않은 타입으로 수정
======================================================================

$ python -m budget_app update --id TX-000002 --type spend
[오류] 타입은 income 또는 expense 만 가능합니다.
[힌트] 예: expense
[exit code] 1
