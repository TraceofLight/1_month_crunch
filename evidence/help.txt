======================================================================
# budget_app  --help
======================================================================
usage: budget_app [-h] <command> ...

파일 기반 가계부 콘솔 프로그램

positional arguments:
  <command>
    add        거래 추가(대화형)
    list       거래 목록(최신순)
    search     거래 검색(최신순)
    summary    월별 요약
    budget     예산 설정/조회
    category   카테고리 관리
    update     거래 수정(옵션 기반)
    delete     거래 삭제
    import     CSV 가져오기
    export     CSV 내보내기
    backup     데이터 백업(보너스)
    recurring  반복 내역(보너스)

options:
  -h, --help   show this help message and exit

# budget_app search --help
======================================================================
usage: budget_app search [-h] [--data-dir DATA_DIR] [--from DATE_FROM]
                         [--to DATE_TO] [--category CATEGORY] [--type TYPE]
                         [--q Q] [--tag TAG] [--limit LIMIT]

options:
  -h, --help           show this help message and exit
  --data-dir DATA_DIR  저장 폴더 경로(기본: ./data)
  --from DATE_FROM     시작일 YYYY-MM-DD
  --to DATE_TO         종료일 YYYY-MM-DD
  --category CATEGORY  카테고리
  --type TYPE          income 또는 expense
  --q Q                메모 키워드
  --tag TAG            태그
  --limit LIMIT        출력 개수 제한
