# 1_month_crunch

## 1. 프로젝트 개요

Python 콘솔에서 동작하는 퀴즈 게임입니다. 기본 Python 문법 문제를 바로 풀 수 있고, 사용자가 직접 퀴즈를 추가하거나 삭제할 수 있으며, 플레이 결과는 `state.json`에 저장되어 다음 실행에도 이어집니다.

현재 구현된 보너스 기능까지 포함하면 다음을 지원합니다.

- 기본 퀴즈 6문항 제공
- 문제 순서를 랜덤으로 섞어 출제
- 이번 라운드에서 풀 문제 수 선택
- 문제별 힌트 확인
- 힌트 사용 시 문제당 10점 감점
- 퀴즈 추가 및 삭제
- 최고 점수 저장
- 최근 플레이 기록 저장 및 표시
- 손상된 `state.json` 복구
- `KeyboardInterrupt`, `EOFError` 안전 종료

## 2. 실행 환경

- Python 3.10+
- Standard Library only
- Windows 11 / Git Bash 기준 확인

## 3. 실행 방법

```bash
python main.py
```

실행 시 아래 메뉴가 출력됩니다.

1. 퀴즈 풀기
2. 퀴즈 추가
3. 퀴즈 목록
4. 퀴즈 삭제
5. 점수 확인
6. 종료

## 4. 주요 기능

### 퀴즈 풀기
- 저장된 퀴즈 중에서 이번 라운드에 풀 문제 수를 먼저 선택합니다.
- 출제 순서는 매번 무작위로 섞입니다.
- 각 문제마다 힌트를 볼지 선택할 수 있습니다.
- 힌트를 사용하면 최종 점수에서 문제당 10점이 차감됩니다.
- 라운드 종료 후 정답 수, 점수, 최고 점수 갱신 여부를 출력합니다.
- 플레이 결과는 히스토리에 누적 저장됩니다.

### 퀴즈 추가
- 문제, 선택지 4개, 정답 번호, 힌트를 입력받습니다.
- 추가 직후 `state.json`에 저장됩니다.

### 퀴즈 목록
- 현재 저장된 전체 퀴즈 개수와 문제 목록을 출력합니다.

### 퀴즈 삭제
- 등록된 퀴즈 목록에서 삭제할 번호를 고른 뒤 한 번 더 확인받습니다.
- 삭제 후 바로 `state.json`에 반영됩니다.

### 점수 확인
- 최고 점수를 표시합니다.
- 최근 플레이 기록 최대 5개를 최신순으로 함께 보여줍니다.
- 각 기록에는 플레이 시각, 문제 수, 정답 수, 점수, 힌트 사용 횟수가 포함됩니다.

### 입력/복구 처리
- 빈 입력, 숫자 범위 오류, 문자 입력은 안내 메시지와 함께 재입력받습니다.
- `Ctrl+C` 또는 `EOFError`가 발생하면 현재 상태를 저장한 뒤 안전하게 종료합니다.
- `state.json`이 없으면 기본 퀴즈로 시작합니다.
- `state.json`이 손상되었거나 구조가 잘못되면 기본 데이터로 복구해 다시 저장합니다.

## 6. 데이터 파일 설명

- 경로: `./state.json`
- 역할: 퀴즈 목록, 최고 점수, 최근 플레이 기록 저장
- 인코딩: UTF-8

### 현재 스키마

```json
{
  "quizzes": [
    {
      "question": "문제",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1,
      "hint": "문제를 푸는 데 도움이 되는 설명"
    }
  ],
  "best_score": {
    "correct": 4,
    "total": 6,
    "score": 56
  },
  "history": [
    {
      "played_at": "2026-04-03T21:22:23",
      "total": 6,
      "correct": 4,
      "score": 56,
      "hint_used": 1
    }
  ]
}
```

### 필드 설명
- `quizzes`: 전체 퀴즈 목록입니다.
- `question`: 문제 문자열입니다.
- `choices`: 길이 4의 선택지 배열입니다.
- `answer`: 정답 번호이며 1~4 범위의 정수입니다.
- `hint`: 해당 문제의 힌트 문자열입니다.
- `best_score`: 최고 기록입니다. 플레이 전에는 `null`일 수 있습니다.
- `history`: 최근 플레이 기록 배열입니다.
- `played_at`: ISO 형식 시각 문자열입니다.
- `hint_used`: 해당 라운드에서 힌트를 사용한 문제 수입니다.

## 7. 클래스 구조

### `Quiz`
- 문제 1개를 표현합니다.
- 문제, 선택지, 정답, 힌트를 보관합니다.
- 출력, 정답 판정, 저장용 직렬화를 담당합니다.

### `QuizGame`
- 전체 게임 흐름을 관리합니다.
- 메뉴 출력, 입력 검증, 퀴즈 진행, 점수 계산, 히스토리 기록, 파일 저장/복구를 담당합니다.

## 8. 기본 데이터 상태

저장소의 `state.json` 샘플은 현재 기본 퀴즈 세트와 동일하게 유지됩니다.

- 기본 퀴즈 6개 모두 실제 힌트를 포함합니다.
- `best_score`는 기본 6문항을 모두 맞춘 예시 값으로 들어 있습니다.
- `history`는 빈 배열로 시작합니다.
