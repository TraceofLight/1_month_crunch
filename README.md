# 1_month_crunch

### 1. Project Abstract

Python 콘솔에서 동작하는 퀴즈 게임을 구현한 프로젝트

- 파이썬 기초 문법을 주제로 기본 퀴즈 6문항을 제공
- 메뉴 기반으로 퀴즈 풀기, 퀴즈 추가, 퀴즈 목록, 최고 점수 확인 기능 제공
- `state.json`에 퀴즈와 최고 점수를 UTF-8로 저장해 재실행 후에도 데이터 유지
- `KeyboardInterrupt`, `EOFError`, 손상된 JSON 파일을 처리해 비정상 종료 없이 복구 가능하도록 구성

> 프로젝트 디렉토리 구조를 나눈 기준

- `main.py`: 콘솔 입출력, 메뉴 흐름, 파일 저장/불러오기까지 게임 전체 동작을 관리
- `state.json`: 기본 퀴즈 데이터와 최고 점수를 저장하는 영속 데이터 파일
- `README.md`: 실행 방법, 기능, 파일 구조, 데이터 스키마를 한 번에 확인할 수 있도록 정리

### 5. Checklist

#### 구현 기능

- 메뉴 출력 및 번호 선택 처리 (V)
- 잘못된 숫자 입력, 빈 입력, 범위 밖 입력 처리 (V)
- `Ctrl+C`, `EOFError` 발생 시 저장 후 안전 종료 (V)
- `Quiz` 클래스와 `QuizGame` 클래스 분리 (V)
- 기본 퀴즈 6개 제공 (V)
- 퀴즈 풀기 기능 및 결과 출력 (V)
- 퀴즈 추가 후 파일 저장 (V)
- 퀴즈 목록 출력 (V)
- 최고 점수 갱신 및 저장 (V)
- `state.json` 손상 시 기본 데이터로 복구 (V)

#### 검증 포인트

- `state.json`이 있으면 저장된 퀴즈/점수를 불러온다.
- `state.json`이 없으면 기본 퀴즈 데이터로 시작한다.
- `state.json`이 손상되면 안내 메시지를 출력하고 기본 데이터로 복구한다.

### 6. Feature Summary

#### 퀴즈 풀기

- 저장된 모든 퀴즈를 순서대로 출제한다.
- 각 문제마다 1~4 사이의 정답 번호를 입력받는다.
- 정답/오답을 바로 알려주고, 종료 시 최종 점수를 계산한다.
- 최고 점수보다 높으면 `best_score`를 갱신한다.

#### 퀴즈 추가

- 문제, 선택지 4개, 정답 번호를 입력받아 새 퀴즈를 등록한다.
- 등록 직후 `state.json`에 저장한다.

#### 퀴즈 목록

- 현재 저장된 전체 퀴즈 개수와 문제 목록을 출력한다.

#### 점수 확인

- 최고 점수가 있으면 점수와 정답 개수를 보여준다.
- 아직 플레이 기록이 없으면 안내 메시지를 출력한다.

### 8. Data File Description

- 경로: `./state.json`
- 역할: 퀴즈 목록과 최고 점수를 저장하는 프로젝트 루트 데이터 파일
- 인코딩: UTF-8

#### 스키마

```json
{
  "quizzes": [
    {
      "question": "문제",
      "choices": ["선택지1", "선택지2", "선택지3", "선택지4"],
      "answer": 1
    }
  ],
  "best_score": {
    "correct": 4,
    "total": 6,
    "score": 66
  }
}
```

- `quizzes`: 문제, 선택지 4개, 정답 번호를 가진 퀴즈 배열
- `best_score.correct`: 최고 점수 기록에서 맞힌 문제 수
- `best_score.total`: 해당 기록의 전체 문제 수
- `best_score.score`: 백분율 점수
- 초기 상태에서는 `best_score`가 `null`일 수 있다.

### 9. Example Notes

- 숫자 입력이 필요한 곳은 앞뒤 공백을 제거한 뒤 검사한다.
- `abc`, 빈 입력, 허용 범위 밖 숫자는 모두 안내 메시지를 출력하고 다시 입력받는다.
- 프로그램 실행 중 `Ctrl+C` 또는 입력 종료가 발생해도 저장 후 종료한다.
- 데이터 파일이 손상되면 프로그램이 중단되지 않고 기본 퀴즈 데이터로 복구된다.
